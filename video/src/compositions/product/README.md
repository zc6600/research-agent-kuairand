# SciOdyssey Product Film

`SciOdysseyProductFilm` is a 180-second product film for the Research Agent. It keeps the visual language of the keynote while reframing the story around the user: what SciOdyssey is, how to start, where existing coding agents fit, and what a verified result looks like.

Render it from `video/` with:

```bash
npm run render:product
```

## Chapter map

| Time | Chapter | Purpose |
| --- | --- | --- |
| 00:00–00:15 | Meet SciOdyssey | Name and positioning |
| 00:15–00:32 | One prompt ends | The long-running research problem |
| 00:32–00:46 | A research layer | World, Scientist, META, Runtime |
| 00:46–01:08 | You bring the question | Start, choose depth, review |
| 01:08–01:38 | Keynote cut | Terminal, evidence, human review, agent handoff |
| 01:38–01:54 | See the run | State, artifacts, and validation |
| 01:54–02:10 | Use the model you trust | Codex, Claude Code, Gemini CLI, and Antigravity as replaceable runtimes |
| 02:10–02:27 | Open the search | Parallel branches with explicit promotion |
| 02:27–02:42 | Evidence, not promises | Recorded KuaiRand-Pure result |
| 02:42–03:00 | Reopen the search | Closing product CTA |

The film intentionally presents SciOdyssey as the durable research workflow around an agent runtime, rather than making unsupported claims that one model is universally better than another.
