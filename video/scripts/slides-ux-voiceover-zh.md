## 如何配音与交付

### 准备视频底片

这版是 Slidev 内的 Vue 动画，目前没有直接嵌入旁白。先录制这版画面，再在剪辑软件中合成声音。

1. 打开 `http://localhost:3030/5`，进入演示全屏；关闭通知，保持页面在前台。
2. 开始屏幕录制，再点击 Replay；将鼠标移出画面，完整播放到结尾。中途不要暂停、跳段或切换标签页。
3. 将录屏导入剪辑软件，裁去开头准备操作与结尾多余停留。把动画归零的第一帧设为时间轴 00:00。
4. 对照八个场景的实际切点。127.2 秒是代码的名义时长；如果录屏时卡顿，实际画面可能更长，以录屏切点为准。

注意：现有 `npm run render:keynote` 导出的是旧版 Keynote，不会包含这次 Vue 动画的修改，因此不能直接用它生成这份配音稿的底片。

### 录音或生成声音

- 真人录音：戴耳机，在安静环境中，按八个场景分别录制。每条开头和结尾留约半秒静音。先试录第 03 段，确认能自然读完，再录其余段落。
- AI 配音：只复制每个口播窗口内的正文，不复制时间码和导演提示；分八段生成，使用同一声音和语速。较长场景可以再按口播窗口拆分。英文产品名先试听，有误读时用工具支持的发音设置修正。
- 可使用的声音提示词：`中文产品演示旁白，自然、清晰、克制，像向同事讲解。语速适中，句间适当停顿，不要广告腔，不读括号或时间码。英文产品名与命令保持英文发音。`
- 保存为 `01-intro.wav` 到 `08-outro.wav`。优先使用 WAV，条件允许时统一 48 kHz；已有清晰 MP3 也可直接使用。

### 对齐、检查、导出

1. 将八条声音放到同一条旁白轨，先按每段第一个口播时间对齐，再按段内时间窗口分句调整。
2. 先对齐“目的标题”，再对齐命令、分支和结果出现的位置。句子偏长时优先缩短措辞或重新录制，不用明显加速整条配音。
3. 保留各段留白，旁白不用覆盖每一秒。背景音乐可选；加入后应明显低于人声。
4. 自动生成字幕后，手动核对 SciOdyssey、research-agent、step、run、parallel 等词。字幕不要遮住命令或结果分数。
5. 完整播放一次，检查文字出现与讲解是否对应、句尾是否被截断、音量是否一致，以及最后一句之后是否留有收尾空间。
6. 输出 MP4，保留 16:9 比例，分辨率与帧率尽量匹配录屏素材。将成片与这份稿件一起保存，方便之后修改。
