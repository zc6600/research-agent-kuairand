04 / INSIGHTS

What the run taught us.

01 · DIVERSITY PRIOR

Different agents search differently. Heterogeneous Scientists turn distinct search styles (local refinement vs. mechanism pivots) into a broader exploration prior.

02 · PARALLEL SYNTHESIS

Parallel search + review produces stronger candidates. Independent Scientists explore in isolation; review selects winning branches for synthesis (observed +0.0040 gain).

03 · ENGINEERING PRACTICE

Branch isolation & unattended continuation. Give each agent an isolated branch to prevent conflicts; use GitHub Actions to run, code, and commit overnight.
