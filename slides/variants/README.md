# SciOdyssey design explorations

These folders are independent Slidev variants generated from the main deck.
They keep the same research story and evidence, but explore different visual
systems so we can compare composition, hierarchy, and diagram language.

The main deck remains one level above this directory in `../slides.md`.

## Variants

- `01-editorial-contrast/` — restrained editorial / Swiss hierarchy.
- `02-evidence-atlas/` — evidence-led modules, source tags, and metric traces.
- `03-runtime-storyboard/` — a live-run framing with an explicit Runtime rail.

Each folder contains its own `slides.md`, styles, assets, build output, and a
ready-to-open PDF export.
