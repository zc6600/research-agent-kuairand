# SciOdyssey design explorations

These folders are independent Slidev variants generated from the main deck.
They keep the same research story and evidence, but explore different visual
systems so we can compare composition, hierarchy, and diagram language.

The main deck remains one level above this directory in `../slides.md`.

## Status

- `candidate` — a complete direction that is still being compared with the main deck.
- `exploratory` — a visual or narrative experiment; it may not follow the full variant template.
- `archive` — retained for reference and no longer an active direction.

## Variants

- `01-editorial-contrast/` — `candidate`; restrained editorial / Swiss hierarchy.
- `02-evidence-atlas/` — `candidate`; evidence-led modules, source tags, and metric traces.
- `03-runtime-storyboard/` — `exploratory`; a live-run framing with an explicit Runtime rail.
- `04-meta-scientist-style/` — `exploratory`; a shorter discovery narrative with oversized black-and-blue headlines.

Each folder contains its own `slides.md`, styles, assets, build output, and a
ready-to-open PDF export. Variant 04 is intentionally listed as exploratory:
it currently has a package manifest but no lockfile and does not yet mirror the
full supporting-file layout of variants 01–03.

The exported PDFs remain next to their self-contained variant sources. The
canonical main-deck and poster exports live in `../exports/current/`, while
superseded root-level main-deck experiments live in
`../exports/archive/main-explorations/`.
