# Variant 02 — Evidence Atlas

This Slidev variant is an evidence-atlas reinterpretation of the current SciOdyssey deck.

It keeps the main deck's frontmatter, 16:9 canvas, Avenir Next / Fira Code typography, white background, chapter-kicker system, shared palette, and existing visual components. The narrative is reorganized around a small set of evidence objects:

- the problem and design claim;
- the persistence boundary and handoff protocol;
- typed research memory and source tags;
- the KuaiRand-Pure evaluation contract;
- the validation metric trace and recovery event;
- scope, limitations, team, and the next trajectory.

All visible claims are grounded in the copied files under `reference/`. The variant is self-contained and does not modify the main deck or variant 01.

Build:

```bash
npm install
npm run build
```
