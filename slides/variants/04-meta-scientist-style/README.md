# SciOdyssey — Meta Scientist style

An independent 9-slide visual direction based on the supplied reference image: oversized black-and-blue headlines, airy white space, pale blue cards, thin rules, and restrained research-world imagery.

This is a separate variant. It does not overwrite the main deck, poster, or existing variants.

## Run

From this directory:

```bash
npm install
npm run dev
npm run build
npm run export
```

The deck keeps SciOdyssey's documented claims and public-validation figures, but presents them as a shorter discovery narrative.
