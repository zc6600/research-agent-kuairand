# Summary thumbnails

These PNGs are captures of the existing Slidev diagrams, with reduced motion
enabled. They are navigation previews, and each Summary card opens its original
slide for legible labels, exact values and full context.

| Asset | Original content |
| --- | --- |
| system.png | System architecture, `.architecture-main` |
| principles.png | Research task, `.research-loop-stages` |
| engineering.png | Engineering practice, `.fieldnote-branch-flow` |
| result.png | Evaluation result, `.bars-widget` |
| trajectory.png | Sustained search, `.trajectory-chart` |
| robustness.png | Failure modes after recovery, `.condensed-visual` |
| comparison.png | Evaluation comparison, `.embedded-token-chart` |
| parallel.png | Parallel research, `.handoff-study` |

The open-world globe and agent logos use the existing assets in the parent
directory. Refresh a thumbnail when its corresponding diagram changes.
