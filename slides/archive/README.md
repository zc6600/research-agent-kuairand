# Archived slide editions

This directory keeps slide deck sources that are no longer part of the active
Slidev build.

- `editions/3d/` — the retired Spatial 3D deck, including its 3D-only Vue components and stylesheet.
- `editions/voyage/` — the retired Voyage editorial deck and its stylesheet.

Their PDF exports live in `../exports/archive/editions/`. The active deck is
still `../slides.md`, with its deliverables in `../exports/current/`.
