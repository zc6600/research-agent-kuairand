# 讲解顺序

网页演示使用右方向键、空格或 PageDown 前进，左方向键或 PageUp 后退。
沿用 Slidev 原生点击序号，不增加 Next 按钮。Shift + 右方向键仍可直接跳到下一页。

封面之后新增目录页，先用一页概览 Problem → System → User Experience → Evaluation，再进入正文。

## 问题页

初始显示三个问题的总览。

1. Workflow：打开能力恢复方案。
2. 收起 Workflow，保留结论。
3. Single Agent：打开搜索轨迹比较。
4. 切到科学有效性问题。
5. 切到 Handoff。
6. Handoff 第一步。
7. Handoff 第二步。
8. Handoff 第三步。
9. Handoff 第四步。
10. 收起 Single Agent，保留结论。
11. Tree Search：打开上下文复用与 token 比较。
12. 切到并行探索。
13. 显示 Reviewer 与汇总。
14. 收起 Tree Search，汇总已获得的结论。

再前进进入系统页，沿用已有的结论汇入架构动画。

## 评估页

初始显示主张。每两步讲一张证据卡：先显示卡片，再打开详情。
详情之后再前进，直接收起详情并显示下一张卡片，不增加单独返回总览的步骤。
顺序为结果、持续搜索、失败恢复、Codex 对照、资源使用。
第十步显示最后一张卡片的详情，再前进进入下一页。

## 其他页面

静态页面沿用正常翻页。ExperienceJourney 保留自动播放和配音节奏。
原有卡片点击、分页标签与收起操作仍可使用；再次按前进或后退时，
恢复到原生点击序号对应的讲解状态。

PDF 是静态总览，不包含交互卡片的全部讲解状态；现场讲解使用网页版本。
