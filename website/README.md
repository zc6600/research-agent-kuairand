# SciOdyssey project website

This folder contains the standalone project-introduction site for Research Agent / SciOdyssey.

## Preview locally

From the repository root:

```bash
python3 -m http.server 8080 --directory website
```

Then open <http://localhost:8080>.

The site is dependency-free: `index.html`, `styles.css`, `script.js`, and the two local image references in `assets/` are enough to serve it from any static host.
