01 / The problem

A trajectory can get better at the wrong kind of better.

Long-running agents accumulate useful knowledge—and also unfinished hypotheses, debugging detours, and local commitments. They can keep refining one basin after a different question deserves attention.

ONE PERSISTENT AGENT

Memory without a reset

Every new experiment is informed by the last one, but the search becomes increasingly local to the current incumbent.

Path dependence compounds over time.
NAIVE RESTART

Fresh cognition, empty hands

Starting from zero breaks the momentum, but throws away evaluator facts, failed experiments, and the implementation that already works.

⌁Failed experimentsnegative evidencelost
▤Research intuitionfallible process lessonslost
◈Retained implementationrecoverable Statelost
Independence without continuity is expensive.

06 / What remains open

A strong result is not the end of the question.

The benchmark validates a complete autonomous loop, not every causal contribution of reset, META, or selective persistence. The next step is to measure when the architecture helps—and when memory itself becomes an anchor.

Model switchingDoes rotating Scientist model families reliably explore different research basins?
