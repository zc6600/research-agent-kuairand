# Archived Research Worlds

These directories are ordinary source snapshots of the independent research
worlds used by the KuaiRand-Pure evidence archive. They are included in the
parent repository so that the reports can link to their code and run records.

The original child-repository Git metadata is intentionally not part of the
parent tree. Local virtual environments, caches, and `competition_data/` remain
ignored because they are reproducible runtime inputs rather than evidence
artifacts. See the parent archive [index](../INDEX.md) for the mapping between
archive names, original project names, and report usage.
